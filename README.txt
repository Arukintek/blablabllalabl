Kyndelik 3

Запуск на Windows
1. Установите Node.js LTS: https://nodejs.org/
2. Распакуйте папку проекта.
3. Дважды щелкните START.bat и дождитесь открытия страницы входа.

При первом запуске START.bat установит зависимости и создаст базу с демо-данными.
Для установки зависимостей нужен интернет. Последующие запуски используют ту же базу.
Не закрывайте окно «Kyndelik server», пока работаете с сайтом.

Бесплатный публичный preview (Render + Neon)
1. Создайте GitHub-репозиторий и загрузите туда проект. Файл backend/.env,
   SQLite-базу и папку backend/node_modules в репозиторий не добавляйте:
   их исключает .gitignore. START.bat создаст локальный .env автоматически.
2. Создайте бесплатный проект PostgreSQL на https://neon.com/ и скопируйте
	строку подключения (лучше pooled connection string).
3. В Render выберите New > Blueprint, подключите GitHub-репозиторий и
	подтвердите создание сервиса из render.yaml.
4. В настройках сервиса Render задайте переменные DATABASE_URL (строка Neon)
	и DEMO_PASSWORD (придумайте пароль не короче 12 символов), затем сохраните
	настройки и запустите Deploy.
5. После успешного Deploy откройте публичный адрес сервиса Render.

Ограничения бесплатного тарифа
Render останавливает бесплатный сервис после простоя; первое открытие после
этого может занять около минуты. Neon хранит данные отдельно от Render, но на
бесплатном тарифе ограничивает вычисления и объём базы; при превышении лимита
запросы могут приостановиться до следующего расчётного периода.

Важно: это учебный preview, не production-система. API пока не проверяет права
пользователей на сервере, а пароли в базе не хэшируются. Используются только
вымышленные демо-данные; не загружайте реальные ФИО, оценки или пароли.
